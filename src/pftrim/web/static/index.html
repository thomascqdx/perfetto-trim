Perfetto Trim

打开一个 trace，在时间轴上选出要保留的区间

输出仍是标准 .perfetto-trace，区间内的信息完整保留，区间开始时的线程状态、计数器和未结束的 slice 会一并带入。

提示：在资源管理器选中文件按 Ctrl+Shift+C 复制路径，回到本页 Ctrl+V 即可打开；也可以直接把文件或文件夹拖进来。
